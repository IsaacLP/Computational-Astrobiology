# Computational Astrobiology — MASS UBMATF 2026

This repository contains coursework for Computational Astrobiology, organized into two top-level sections: a research project and a series of ML tutorials applied to astrobiology problems.

## Project

`project/` contains a simulation-to-ML pipeline for detecting exoplanet transits in stellar light curves affected by stellar activity, built around ESA PLATO mission preparation tools. See [`project/README.md`](project/README.md) for full details.

## Tutorials

`tutorials/` contains eleven notebooks covering core ML and deep learning methods, each applied to astronomical or astrobiological datasets (primarily NASA Exoplanet Archive and PLATO-like spectra):

| # | Topic |
|---|-------|
| 1 | Supervised Learning — Regression |
| 2 | Naive Bayes classification |
| 3 | Neural networks and gradient descent |
| 4 | Support Vector Machines (SVM) |
| 5 | Random Forests |
| 6 | GPU computing with CUDA for ML |
| 7 | Exoplanet spectra analysis on GPU |
| 8 | Gradient descent and ML demo on NASA Exoplanet Archive |
| 9 | Principal Component Analysis (PCA) |
| 10 | Convolutional Neural Networks (CNN) |
| 11 | Vision Transformers |
